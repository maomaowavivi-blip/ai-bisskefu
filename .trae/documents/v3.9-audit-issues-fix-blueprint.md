## 二、修复方案

### 修复 1:OrderQueryWorkflow 接 channelOrder(替代坏网关)

**文件**:`api/Workflow/OrderQueryWorkflow.php`

**改法**(经 2 次审计修正):**不调 buildRoomCardLink**(依赖 thumb),**也不调 getRoomCard**(返回云房卡字段,无订单信息),改为**直接调 channelOrder API**(实测确认 check_in/check_out/unit_name/price 字段存在):

```php
// v3.9:替代 callGateway 坏网关,直接调 channelOrder 查订单
function queryChannelOrder(PDO $db, string $channelOrderId): ?array
{
    $user = trim(pcGet($db, 'roomcard.username', ''));
    $pwd  = trim(pcGet($db, 'roomcard.password', ''));
    if ($user === '' || $pwd === '') return null;

    $url = "https://apicenter.sujia365.com/index.php/openapi/order/channelOrder"
        . "?username=" . urlencode($user)
        . "&pwd=" . $pwd
        . "&channel_order_id=" . urlencode($channelOrderId);

    $ch = curl_init($url);
    curl_setopt_array($ch, [CURLOPT_RETURNTRANSFER => true, CURLOPT_TIMEOUT => 10]);
    $resp = curl_exec($ch);
    $httpCode = curl_getinfo($ch, CURLINFO_HTTP_CODE);
    curl_close($ch);
    if ($httpCode !== 200 || !$resp) return null;

    $data = json_decode($resp, true);
    if (!isset($data['code']) || intval($data['code']) !== 1 || empty($data['data']['order'])) return null;
    return $data['data']['order'];
}
```

handle() 内:
```php
$order = queryChannelOrder($this->db, $orderNo);
if (!$order) {
    return WorkflowResult::text('没有查询到这个订单号，请确认订单号是否正确，或拨打 400-155-9959 联系管家～', 'OrderQueryWorkflow');
}
$reply = "订单查询成功：\n"
    . ($order['unit_name'] ? "房型：{$order['unit_name']}\n" : '')
    . ($order['check_in'] ? "入住：" . date('Y-m-d', strtotime($order['check_in'])) . "\n" : '')
    . ($order['check_out'] ? "离店：" . date('Y-m-d', strtotime($order['check_out'])) . "\n" : '')
    . ($order['price'] ? "房价：¥{$order['price']}\n" : '')
    . '如需查看云房卡请前往微信客服发送订单号获取。';
return WorkflowResult::text($reply, 'OrderQueryWorkflow');
```

**注意**:
1. 复用 `roomcard.username/password` 配置(已存在)
2. 无订单 → "查不到该订单号"
3. web 端回文本;云房卡卡片仍由微信端(v3.7)负责

### 修复 2:拒绝话术(3 处)

**2a. A5 私下交易** → IntentClassifier 加 `rule:pre_sales` 变体?不,直接改 PreSalesWorkflow 加检测:

**方案**:在 `PreSalesWorkflow::handle()` 检测"微信转/直接订/私下"关键词 → 回拒绝话术:
```php
if (preg_match('/微信转|私下|直接订|不走平台|绕过平台/u', $message)) {
    return WorkflowResult::text('抱歉，为保证您的资金安全，我们不接受私下转账订房。请前往美团、携程、飞猪等 OTA 平台搜索「柚光民宿」下单～', 'PreSalesWorkflow');
}
```

**2b. E2 AI身份** → IntentClassifier 加 AI 身份识别:
```php
// 在 isSmallTalk 之前或之后加
if (preg_match('/你是(不是)?(AI|机器人|人工|真人)/u', $message)) {
    return IntentContext::of(Intent::SMALL_TALK, 0.9, [], 'rule:ai_identity');
}
```
SmallTalkWorkflow 的 prompt 会自然回答"我是小柚"。

**2c. E4 隐私查询** → HandoffTriggers 或 IntentClassifier 识别"查手机号/别人订单":
```php
// 在订单判定之前
if (preg_match('/查.*(手机号|电话|身份证|别人的订单|他.*订单)/u', $message)) {
    return IntentContext::of(Intent::KNOWLEDGE, 0.9, [], 'rule:privacy_refuse');
}
```
KnowledgeWorkflow KB 加一条"隐私查询拒绝"话术,或直接返回固定话术。

### 修复 3:拦截话术优化

**3a. A6 砍价** → isPreSalesQuery 已匹配"多少钱"类;A6"能便宜点吗"未命中。在 `isPreSalesQuery` 加:
```php
'/便宜|优惠|打折|折扣|减价/u',
```

**3b. F 注入拦截话术** → `checkInputSafety` 的 injection 返回话术改为更自然的:
