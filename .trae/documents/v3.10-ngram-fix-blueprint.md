# 修改蓝图 v3.10:修复搜索误匹配("空房→空调")

**日期**:2026-08-14
**作者**:波尼(执行),苏鸣(审核)
**状态**:待审计

---

## 一、问题

**现象**:用户问"有空房吗",AI 回"所有房间都配备空调"(答非所问)。

**根因(实测确认)**:
- `PromptEngine::_searchByNgram()` 用 2 字窗口切 n-gram
- "有空房吗" → grams: `有空房吗,有空房,空房吗,有空,空房,房吗`
- 2 字 gram **"有空"** 匹配到 KB "房间有**有空**调吗" 的子串 → 误命中
- n-gram 下限 2 字太短,产生大量无意义子串

**补充证据**:售前判定(PRE_SALES)已修复"有空房吗"→OTA,但**如果用户问"有空房吗"没触发售前关键词**(如"有空房"出现在长句),KB 检索仍会误匹配。

---

## 二、修复方案(经 3 轮审计定稿)

### 修改 1(核心):`searchKnowledge()` 入口拦截售前类查询

**文件**:`api/PromptEngine.php`

```php
public static function searchKnowledge(PDO $db, string $query, int $maxCount = null): array {
    $maxCount = $maxCount ?? self::KB_MAX_ITEMS;
    $q = mb_substr(trim($query), 0, 100);
    if (mb_strlen($q) < 2) return [];

    // v3.10:售前类查询不进 KB(有空房/有房吗 → 售前分流,避免"空房→空调"误匹配)
    if (preg_match('/有空房|有房吗|还有房|空房吗|有没有房|有房没|订房|预订|多少钱|价格|便宜|优惠/u', $q)) {
        return [];
    }
    ...
}
```

**理由**(审计实测):
- "有空房吗" 的 2 字 gram "有空" 必然匹配 "房间有**有空**调吗" — 任何 n-gram 方案都治不了
- 售前类查询本应由 PRE_SALES 分流 → KB 返回空是正确行为(交给售前流程)
- "订房/价格/优惠" 等词同样属于售前,提前拦截防止被 KB 抢答

### 修改 2:`_searchByNgram()` 2 字 gram 降权

```php
// 命中评分:gram 越长分越高,2 字 gram 降权,前缀加分
$score = mb_strlen($g) * 10 + ($pos === 0 ? 5 : 0);
if (mb_strlen($g) === 2) $score -= 3;
```

**注意**:此修改为辅助,主拦截在修改 1。
