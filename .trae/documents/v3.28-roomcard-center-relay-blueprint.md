### 1.2 旧卡为什么"旧"（关键证据）

生产实测两套接口对同一订单 `123456789`（2026-10-23）：

| 维度 | 旧宿家 `byChannelOrder` | 新中台 `room_card/byOrder` |
|---|---|---|
| 卡数量 | **1 张**（只 room_id=1374） | **2 张**（roomId 1374 + 1437） |
| 房号 | shareText 写「万达广场测试的**1001**号房间」 | roomCode=**10002**（1374）/ 10001（1437） |
| qrCodeId | `SnXVN2YzgcztIXBYajaGbQ` | `ushWrcwEIGAh43lClkqDxg` / `SEElqxWKzjdiRtfXslxyhQ` |
| appid / path | share_bundle.miniapps[0] 提供 | **不提供** |
| urlLink | `weixin://dl/business/?t=...` | **不提供** |
| 记录来源 | 宿家 id=892，createtime 2026-10-13 14:14 | 中台 cardId 37 / 38 |

→ 旧卡房号与中台当前房间数据**不一致**，且一单多房只发 1 张。这才是客户"收到旧云房卡"的实质。

### 1.3 新接口实测（2026-10-23，GET + query string）

```
GET https://business.youguang8488.com/api/relay/room_card/byOrder
    ?username=13768370505&password=<中台密码>&channel_order_id=123456789
```

| 用例 | 实测结果 |
|---|---|
| 正常订单 | `code=1`，`msg=该订单已生成过房卡，可直接使用`，`data.created=false`，`data.cards[]` 2 张 |
| 鉴权 | **只认中台凭据**；旧宿家密码 → `code=0 账号或密码错误`；无凭据同错 |
| `tenant_id` | 可选，带不带都 `code=1` |
| `force` / `room_id` 参数 | 被忽略（仍返 2 张） |
| 不存在的订单 | `code=0 未找到该渠道订单号，请核对后重试`（**不写库**） |
| 缺 `channel_order_id` | `code=0 请输入渠道订单号` |
| 同路径加后缀 | `/room_card/byOrder/share`、`/byOrder/generate` 均返回**同一份** byOrder 响应（路由前缀匹配，无独立端点） |
| 其它候选路径 | `/room_card/{generate,create,list,detail,link,share,byQrCode}`、center 站同路径 → nginx 404 |
| 响应字段 | `qrCodeId, cardId, roomId, roomCode, toponym, address, createQrCodeTime, expireTime, deposit, isDeposit, isAuth, isPoliceAuthed, isInvalid, generateType, channelOrderId, statusText` |

**结论：新接口只有 1 个端点 `room_card/byOrder`，无独立 generate 端点**（无卡时是否自动生成，见 §六 待验证）。

## 二、目标

1. 云房卡主链路切到中台 `room_card/byOrder`，房卡数据**以中台为准**（与 v3.27「中台为准」原则一致）
2. 保留 **A 样式原生小程序卡片**（企微 miniprogram 消息，appid + pagepath）
3. 一单多房发多张卡（新接口天然返回 N 张）
4. 新接口不可用时**自动回退旧宿家接口**，业务不中断
5. 端点地址可配置（DB 覆盖），不再硬编码

**不做**：不删除旧宿家接口代码（回退要用）；不改小程序；不做后台配置界面（见 §六 P2）。

## 三、改动方案

### 3.1 改动文件（1 个）

| 文件 | 改动 |
|---|---|
| `api/wecom_kf_roomcard_v37.php` | 新增 3 个函数 + 改 `buildRoomCardDeliveries()` / `buildRoomCardDelivery()` |

### 3.2 新增函数

| 函数 | 职责 |
|---|---|
| `roomCardApiUrl(PDO $db): string` | 读 `roomcard.api_url`，缺省用常量 `ROOMCARD_CENTER_API_URL` |
| `fetchCenterRoomCards(PDO $db, string $orderId, ?string &$err = null): array` | 调中台 byOrder；`$err=null` 表示成功（含 0 张卡），非 null 表示调用失败 |
| `parseCenterRoomCard(PDO $db, array $card): ?array` | 中台卡 → 企微小程序卡片参数 |

### 3.3 字段映射（中台卡 → A 样式卡片）

| 企微字段 | 取值 | 说明 |
|---|---|---|
| `appid` | `platform_config.ai.miniprogram.appid`（现值 `wxc5bd79445fd465bb`） | 平台配置，不硬编码 |
| `pagepath` | `ai.miniprogram.pagepath`（现值 `pages/index/index`）+ `.html?qrCodeId={qrCodeId}` | **与宿家 share_bundle 的 path 结构完全同构**（宿家：`pages/index/index.html?qrCodeId=SnXVN2YzgcztIXBYajaGbQ`，客户点得开） |
| `title` | `您的房间为 {roomCode}` | 缺 roomCode 时用「云房卡」 |
| `desc` | `toponym` | 企微 miniprogram 消息体实际不传 desc，仅作排查 |
| `thumb_media_id` | 沿用 `getThumbMediaIdCached()`（60h 自愈 + 40007 重发） | 不变 |
| `url` | **空** | 中台不返回 urlLink → B 样式 link 兜底在新链路不可用 |

### 3.4 凭据（红线）

- 中台账号密码**复用** `platform_config.center.username` / `center.password`（与 v3.26 订单/房源同一账号，值已在生产 DB）
- 密码只出现在 curl URL 内，**不进日志、不进源码、不进 commit**；日志只打 `code` / `msg` / HTTP 码
- `roomcard.username` / `roomcard.password`（旧宿家凭据）**保留不动**，供回退路径使用

### 3.5 回退策略

| 情况 | 行为 |
|---|---|
| 新接口 `code=1` 且有卡 | 直接用新卡，**不回退** |
| 新接口 `code=1` 但 0 张卡 | **不回退**（中台说没有就是没有，避免旧接口生成旧卡） |
| 新接口 HTTP 失败 / `code=0`（鉴权、订单不存在等） | 回退旧宿家 `generateAllRoomCards()`，日志打 `[roomcard] fallback to legacy sujia api` |
| 新接口 401/账号密码错 | 同样回退，业务不中断 |

### 3.6 不动的部分

- `getRoomCard()` / `generateRoomCard()` / `generateAllRoomCards()` / `parseRoomCardDelivery()` / `parseRoomCardForLink()` —— 旧链路原样保留（回退 + `buildRoomCardLink()` 仍需 urlLink）
- `api/wecom_kf.php` —— 调用点 `buildRoomCardDeliveries()` 签名不变，**零改动**
- `ai.miniprogram.*` 配置 —— 不新增、不修改

## 六、风险与回滚

| 风险 | 等级 | 缓解 |
|---|---|---|
| 中台 qrCodeId 小程序端解析不了 → 客户点开空白 | 🟠 | 蓝图中 `pagepath` 与宿家同构（只换 token）；验收第 6 项人工确认；异常时立即回滚（见下） |
| 新接口无 urlLink → B 样式兜底失效 | 🟡 | A 样式是既定发布行为（v3.15.2 起）；`buildRoomCardLink()` 保留旧实现，仅故障对照用 |
| 中台不可用 → 房卡发不出 | 🟢 | 自动回退旧宿家接口 |
| 密码进 URL 被日志记录 | 🟢 | 代码不打印 URL；错误日志只打 code/msg/HTTP 码 |

**回滚**（1 分钟内）：

```bash

scp api/wecom_kf_roomcard_v37.php root@43.138.217.6:/www/wwwroot/aibisskefu/api/
# 2. md5 校验
# 3. php-fpm reload
# 4.（可选）停用新端点
# UPDATE platform_config SET value='' WHERE `key`='roomcard.api_url';
```
