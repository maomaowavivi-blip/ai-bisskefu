    public static function process(...): array {
        try {

            return [

                'msg'  => 'ok',
                'data' => $response,  // ← 只含业务字段：reply / rich_content / room_pick / handoff_status / is_verified / intent / confidence / workflow

        }
    }
}

## 四点九、修正 22 落地：history shape 防御

```php
private static function detectRecentOrderNo(array $history): ?string {
    if (!is_array($history) || empty($history)) return null;
    $start = max(0, count($history) - 5);
    for ($i = count($history) - 1; $i >= $start; $i--) {
        $msg = $history[$i] ?? null;
        if (!is_array($msg)) continue;
        $content = $msg['content'] ?? ($msg['text'] ?? '');
        if (!is_string($content)) continue;
        if (preg_match('/\d{16,}/', $content, $m)) {
            return $m[0];
        }
    }
    return null;
}
```

## 四点十四、修正 31 落地：静态缓存问题

### PHP-FPM 多进程模型背景

MAMP 用 Apache + PHP-FPM。每个 HTTP 请求由独立的 worker 进程（或线程池）处理。**`static` 变量是进程级的，不是全局共享的**：
- Worker A 的 `static $pipelineEnabledCache` ≠ Worker B 的 `static $pipelineEnabledCache`
- 切换瞬间：Worker A 缓存 `false`，Worker B 缓存 `true` → 行为不一致

### 推荐方案：方案 C（每次读 platform_config，不缓存）

```php
class ChatPipeline {
    /**
     * 修正 31：放弃 static cache
     * 理由：PHP-FPM 多进程下 static 缓存行为不一致，文件缓存需处理并发写入
     * 妥协：每次读 platform_config，多 1 次 DB roundtrip（~1ms，UNIQUE KEY uk_key 索引 seek）
     * 收益：行为 100% 确定，无并发风险
     */
    private static function isPipelineEnabled(AgentConfig $config): bool {
        return $config->get('pipeline.enabled', 'false') === 'true';
    }

    public static function process(...): array {
        // 修正 32：Pipeline 入口只 new 一次
        $config = new AgentConfig($db);
        // 后续 IntentClassifier、Workflow 全部接收 $config 参数，禁止各自 new
        // ...
        if (!self::isPipelineEnabled($config)) {
            throw new \RuntimeException('Pipeline disabled');
        }
        // ...
    }
}
```

### 备选方案 B（文件缓存，仅当 platform_config 性能成为瓶颈时启用）

```php
private static function isPipelineEnabled(AgentConfig $config): bool {
    $cacheFile = '/tmp/aibisskefu_pipeline_enabled';
    $ttl = 60;
    if (file_exists($cacheFile) && (time() - filemtime($cacheFile)) < $ttl) {
        return trim(@file_get_contents($cacheFile)) === 'true';
    }
    $enabled = $config->get('pipeline.enabled', 'false') === 'true';
    @file_put_contents($cacheFile, $enabled ? 'true' : 'false', LOCK_EX);
    return $enabled;
}
```

**适用场景：** chat.php 每秒 > 100 QPS，platform_config 读成为瓶颈时。

## 六、IntentClassifier（**关键修正：LLM 不参与分类**）

```php
class IntentClassifier {
    /**
     * 修正 3：LLM 不参与 Intent 判定
     * 规则失败 → 直接 UNKNOWN → UnknownWorkflow 用 LLM 生成兜底话术
     * Intent 永远由规则判定，避免 fast path 被 LLM 拖慢（当前 30ms → LLM 引入 1.5s）
     *
     * 修正 11：凭证识别用 AgentConfig 实例方法（与现有 chat.php 一致）
     * 修正 12：history 中有近期订单号 → 增强凭证识别（防「上一轮查单/本轮问WiFi」漏判）
     */
    public static function classify(string $message, array $ctx): IntentContext {
        $config = $ctx['config'];
        $history = $ctx['history'] ?? [];

        // 1. 转人工（含 priority）
        $match = HandoffTriggers::matchKeyword($ctx['db'], $message);
        if ($match !== null) {
            return IntentContext::of(Intent::HUMAN, 1.0, [], 'rule:handoff_keyword', priority: $match['priority'] ?? 99);
        }

        // 2. 凭证类 → 云房卡引导（独立 Workflow，修正 1）
        //    修正 11：优先用 AgentConfig 实例方法（与 chat.php:319 一致）
        //    修正 12：history 增强判定
        $isCredential = $config->isCredentialQuery($message);
        $hasRecentOrderNo = self::detectRecentOrderNo($history);
        if ($isCredential || ($hasRecentOrderNo && self::isPotentialCredential($message))) {
            return IntentContext::of(
                Intent::ROOM_PASSWORD_QUERY,
                $isCredential ? 0.95 : 0.75,
                $hasRecentOrderNo ? ['order_no' => $hasRecentOrderNo] : [],
                $isCredential ? 'rule:credential' : 'rule:credential_with_history'
            );
        }

        // 3. 房间意图（已有 isRoomIntent + matchesEntry）
        $roomKeywords = RoomQueryFlow::getRoomKeywords($ctx['db']);
        if (RoomQueryFlow::isRoomIntent($message, $roomKeywords)) {
            $slots = [];
            if (SidecarIntent::looksLikeOrderNo($message)) {
                $slots['order_no'] = $message;
            }
            return IntentContext::of(Intent::ROOM_QUERY, 0.9, $slots, 'rule:sidecar_keyword');
        }

        // 4. 查订单（冻结块，修正 2）
        if (preg_match('/^order_query:|订单|查单/u', $message)) {
            return IntentContext::of(Intent::ORDER_QUERY, 0.85, [], 'rule:order_keyword');
        }

        // 5. 闲聊（已有 isChitchat）
        if (SidecarIntent::isChitchat($message)) {
            return IntentContext::of(Intent::SMALL_TALK, 0.8, [], 'rule:chitchat');
        }

        // 6. KB 命中 → KNOWLEDGE（注意：这是 DB 查询，注意 7.1）
        $kb = PromptEngine::searchKnowledge($ctx['db'], $message, 3);
        if (!empty($kb)) {
            return IntentContext::of(Intent::KNOWLEDGE, 0.7, [], 'rule:kb_match', kbItems: $kb);
        }

        // 7. 都失败 → UNKNOWN（不调 LLM！交由 UnknownWorkflow 生成兜底话术）
        return IntentContext::of(Intent::UNKNOWN, 0.0, [], 'fallback');
    }

    /**
     * 修正 12 辅助方法：从 history 中提取最近一条订单号
     */
    private static function detectRecentOrderNo(array $history): ?string {
        for ($i = count($history) - 1; $i >= 0 && $i >= count($history) - 5; $i--) {
            $content = $history[$i]['content'] ?? '';
            if (preg_match('/\d{16,}/', $content, $m)) {
                return $m[0];
            }
        }
        return null;
    }

    /**
     * 修正 12 辅助方法：消息可能涉及凭证但未直接命中关键词
     * （如「密码」「WiFi」「门锁」「刷脸」「押金」等弱信号）
     */
    private static function isPotentialCredential(string $message): bool {
        $weakSignals = ['密码', 'wifi', 'wi-fi', '门锁', '门禁', '刷脸', '押金', '开锁', '进不去', '连不上', '上不了网'];
        $msg = mb_strtolower($message, 'UTF-8');
        foreach ($weakSignals as $sig) {
            if (mb_strpos($msg, $sig) !== false) {
                return true;
            }
        }
        return false;
    }
}
```

class ChatPipeline {
    /**
     * 修正 5：拆出 chat.php 主循环

    public static function process(

        string $message,
        array $history,
        PDO $db,
        AgentConfig $config,
        string $visitorHash,
        string $ip,
        string $channel = 'web'  // 修正 16：web / wechat_mp / wechat_msg / openapi

        // 修正 19：Pipeline 开关（PR2 默认 false，PR3 改 true）
        if ($config->get('pipeline.enabled', 'false') !== 'true') {
            // 开关未开 → 走旧 chat.php 逻辑（PR2 阶段）
            // PR3 切换后这段不会再执行，但保留作为安全网
            throw new \RuntimeException('Pipeline disabled, fallback to chat.php old path');

        ]);

        // 5. 路由 → Workflow
        $result = IntentRouter::route($intentCtx);

        // 6. 渲染（修正 16：channel 决定是否带 rich_content）
        $response = ReplyRenderer::render($result, $channel);

        // 7. 持久化 + 审计
        ChatLog::record($db, $sessionId, $message, $result, $intentCtx, $visitorHash, $ip, $start, $channel);
        SessionState::save($db, $sessionId, $intentCtx, $result);

        $response['elapsed_ms'] = (int)((microtime(true) - $start) * 1000);
        $response['intent'] = $intentCtx->intent;          // 打点
        $response['confidence'] = $intentCtx->confidence; // 打点
        $response['workflow'] = $result->workflowName;   // 决策 3 落地
        return $response;
    }

    /**
     * 修正 13：限流逻辑内联（不开新文件）
     * 完整复制 chat.php:287-303 + 加注释

    private static function enforceRateLimit(PDO $db, string $ip): void {
        $xff = $_SERVER['HTTP_X_FORWARDED_FOR'] ?? '';
        $ip = $xff ? trim(explode(',', $xff)[0]) : ($_SERVER['REMOTE_ADDR'] ?? $ip);
        $rateKey = 'rl:' . $ip;
        $now = date('Y-m-d H:i:s');
        $st = $db->prepare("SELECT count, window_start FROM rate_limits WHERE key_str = ?");
        $st->execute([$rateKey]);
        $rl = $st->fetch();
        if ($rl && strtotime($rl['window_start']) > time() - 60) {
            $db->prepare("UPDATE rate_limits SET count = count + 1 WHERE key_str = ?")->execute([$rateKey]);
        } else {
            $db->prepare("INSERT INTO rate_limits (key_str, count, window_start) VALUES (?, 1, ?) ON DUPLICATE KEY UPDATE count = 1, window_start = ?")->execute([$rateKey, $now, $now]);
        }
        $stmt = $db->prepare("SELECT count FROM rate_limits WHERE key_str = ?");
        $stmt->execute([$rateKey]);
        $currentCount = intval($stmt->fetchColumn());
        if ($currentCount > 20) {
            chatResponse(429, '请求过于频繁，请稍后再试');
        }
    }
}

class SessionState {
    /**
     * 修正 14：必须包含 order_context_cache 读取

    private static function loadOrderCache(PDO $db, string $sessionId): ?array {
        $stmt = $db->prepare('SELECT * FROM order_context_cache WHERE session_id = ? AND expires_at > NOW() LIMIT 1');
        $stmt->execute([$sessionId]);
        $cache = $stmt->fetch();
        return $cache ?: null;
    }

    public static function save(PDO $db, string $sessionId, IntentContext $ctx, WorkflowResult $result): void {
        // 1. room_session 按需更新
        if (in_array($ctx->intent, [Intent::ROOM_QUERY, Intent::ORDER_QUERY], true)) {
            self::saveRoomSession($db, $sessionId, $ctx, $result);
        }
        // 2. order_cache 按需更新
        if ($ctx->intent === Intent::ORDER_QUERY && $result->orderCache) {
            self::saveOrderCache($db, $sessionId, $result->orderCache);
        }
        // 3. handoff 按需创建
        if ($ctx->intent === Intent::HUMAN) {
            self::createHandoff($db, $sessionId, $ctx);
        }
    }
}

- 脚本: `scripts/capture_golden_baseline.php`
- 输入: 50 条精心设计的测试输入(覆盖 §十二 10 条核心 + 边界场景)

- 用途: PR1-PR4 每完成一个,跑一次 diff,0 差异 = 通过

### 决策 5 落地:UnknownWorkflow 4 道保险

1. 先试 KB 弱匹配(`PromptEngine::searchKnowledge` + 可选 `kbSemanticSearch`)
2. 有弱匹配 → 转 KnowledgeWorkflow(不调 LLM)
3. 无弱匹配 → 调 LLM,**硬超时 1.2s** + `max_tokens=80` + `temperature=0.2` + `thinking:disabled`
4. 必经 `PromptEngine::finalizeReply`(上次的指纹校验拦胡编)
5. LLM 超时/失败 → 固定话术"这边暂时没有查到..."

### 决策 3 落地:chat.html 前端打点(仅 console,不暴露 UI)

```javascript
// chat.html 在 chatResponse 回调末尾追加

        intent: data.intent,
        confidence: data.confidence,
        workflow: data.workflow,
        elapsed_ms: data.elapsed_ms,
    });
}
```

后端约束: `ChatPipeline.process()` 返回数组必须包含 `intent` / `confidence` / `workflow` 字段。
