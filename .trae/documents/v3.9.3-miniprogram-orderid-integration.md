## 二、需要小程序做的改造

### 2.1 `pages/index/index` 支持订单号参数

**当前**:`pages/index/index` 是固定路径,无参数

**改造后**:`pages/index/index?channel_order_id=5035035963841932965`(订单号带过去)

```javascript
// pages/index/index.js
Page({
  onLoad(query) {
    const channelOrderId = query.channel_order_id || '';
    if (channelOrderId) {
      this.loadRoomCard(channelOrderId);
    }
  },

  async loadRoomCard(channelOrderId) {
    // 调你们后端的 /generateByChannelOrder 接口
    // 或小程序端直接调 apicenter.sujia365.com
    const resp = await wx.request({
      url: 'https://apicenter.sujia365.com/index.php/openapi/room_card/generateByChannelOrder',
      method: 'POST',
      header: { 'content-type': 'application/json' },
      data: {
        username: '13768370505',
        pwd: '7s9Kp2&qG5',
        channel_order_id: channelOrderId,
      }
    });
    // resp.data.data.cards[0].card 里就有完整数据
    // 包含:roomCode / expireTime / wifiPassword / lockPassword / 押金状态 等
  }
});
```

### 2.2 显示数据

拿到 `cards[0].card` 后,渲染到页面的绿色大卡里:

| 字段 | 显示位置 |
|---|---|
| `roomCode` | 房号 |
| `expireTime` | 有效期 |
| `toponym` | 小区名 |
| `address` | 地址 |

> ⚠️ **敏感字段绝对不进 AI 客服回复**(密码/押金/公安验证等)。**客户在小程序里点击按钮**展开密码是 OK 的(用户在自己设备上看自己数据),但 AI 客服代码生成文案时不能包含这些字段。

| 敏感字段 | 在小程序内的呈现 |
|---|---|
| `wifiName` / `wifiPassword` | wifi密码按钮(点击展开)|
| `roomPassword` | 开锁密码按钮(点击展开)|
| `deposit` / `isDeposit` | 押金状态 |
| `urlLink` | 分享/复制按钮 |

### 2.3 客户没带订单号的情况
