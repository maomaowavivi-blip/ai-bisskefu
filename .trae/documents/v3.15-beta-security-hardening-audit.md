## 一、审计依据

9. 当前 Git 追踪文档和历史中存在 VPS及宿家有效凭据。
10. `/www/backup/database` 为空，系统没有应用日志轮转配置。
11. 生产与本地知识库均为 149 条，带 HTML 标签答案为 0；人设 HTML 字段为 0。
12. v3.14 云房卡真实链路已成功；58 个 PHP、2 个 Shell 语法检查通过；8/8 Intent、4/4 核心 Workflow 事务回滚测试通过。

## 三、审计中发现并已修正的蓝图陷阱

### 1. Embedding 不能只加 `adminGuard()`

`knowledge.php` 和 `openapi.php` 当前通过 HTTP 自请求调用 Embedding。直接保护会让后台向量化和 OpenAPI 搜索一起失效。蓝图已改为“函数层内部调用 + HTTP 调度器认证”。

### 2. Sidecar stats 保护后会打断设置页

`admin/settings.html` 的 stats 请求当前没有 `getHeaders()`。蓝图已把前端 Header 修改纳入同一原子变更。

### 3. 不能直接删除人工接管三个文件

项目硬约束禁止删除，且 `chat.php` 当前仍 `require HandoffWorkflow.php`。蓝图改为：先移除引用和轮询，API 返回 410，文件保留。没有 `git rm`。

### 4. 不能立即启用严格 CSP

后台大量脚本内联。直接设置 `script-src 'self'` 会让后台瘫痪。蓝图只加不会破坏现有功能的响应头，CSP 后续单独迁移。

### 5. 不能把微信游标保存继续放在 `syncMsg()` 内

游标必须由整批处理结果决定，且房卡成功分支不能提前 `continue`。蓝图已明确 `syncMsg()` 只返回数据，整批成功后再保存游标。

### 6. 不能把数据库密码写入 cron

生产 MySQL 已确认不能通过 root socket 免密连接。蓝图选择宝塔数据库备份任务，并以恢复演练作为有效性标准。

### 7. 不能把 Git 历史重写和普通上线绑在一起

历史强推会影响协作者和回滚。正确顺序是先轮换凭据、清理当前版本、完成代码上线；历史重写另做备份和协作者确认。内测 Gate 判断依据是旧凭据已失效。

### 8. 不能只封 `/docs`，还要封根目录文档和模板

仓库根目录存在 `AGENTS.md`、PRD、代码说明和 CSV，`templates/` 下还有业务配置 JSON。蓝图初稿只封了部分目录，审计后已补充 `/templates/` 以及 `md/csv/yaml/ini/conf` 静态扩展阻断。修正后的 Nginx 片段已在生产同版本 Nginx 上用临时配置执行 `nginx -t`，语法通过；没有 reload，也没有修改线上配置。

### 9. 人设纯文本化必须包含服务端

只改 `admin/persona.html` 不能阻止直接 API 写入 HTML。审计后已把 `api/persona.php` 纳入文件清单，保存和展示两端同时文本化。

### 10. 不能把整个 `logs/` 当历史日志清空

`logs/` 里同时存放房卡缩略图 media ID、微信 cursor 和 msgid 去重缓存，它们是在线状态，不是普通日志。蓝图初稿的“清空历史日志”存在误伤风险，审计后已限定为：先复制归档，只截断 `wecom_kf.log`，cursor/cache/media ID 原地保留。

## 四、执行前置条件

以下事项必须由外部状态确认，开发代码不能代替：

1. 宿家能够轮换当前接口密码或提供新的专用账号。
2. VPS 新 SSH 凭据已安全交付并实测登录成功。
3. 宝塔面板数据库备份任务可以覆盖主库和 Sidecar。
4. 内测人员只使用指定测试订单，不使用真实住客订单做压力测试。

任一凭据无法轮换时，Gate A 不得标记 PASS。

## 五、实现阶段强制检查点

1. 修改前重新执行 `git status`，不得带入两个现有未追踪 v3.8 文档。
2. 代码实现必须按蓝图原子分组，先 XSS/认证，再停用接管，再微信可靠性。
3. SQL 先在本地备份后执行；生产 SQL 在 VPS 快照和数据库备份后执行。
4. 上传只能使用明确文件清单；禁止 `git add -A`，禁止把三个人工接管文件提交为删除。
5. 生产备份文件只能放 Web 根目录外；不得再生成 `*.bak` 或 `*.before-*` 到站点目录。
6. 测试日志必须脱敏；不得输出真实订单号、手机号、客户 ID、密码或 Token。
7. 全部验收后才允许 commit、push 和内测放行。
