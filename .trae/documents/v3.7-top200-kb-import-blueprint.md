## 三、CSV 数据格式(导入 API 已支持)

```csv
问题,答案,关键词,分类名
WiFi密码多少?,请查看入住当天发送的云房卡,未收到请提供订单号查询。,wifi,wifi密码,无线网络,网络连接,入住与设备
几点可以入住?,标准入住时间为当日14:00;如需提前入住请联系掌柜视房态协调。,入住时间,几点入住,入住,check in,入住与设备
```

**字段说明**:
- `问题`:必填,标准问题
- `答案`:必填,标准答案
- `关键词`:逗号分隔,用于关键词匹配 + 帮助向量化
- `分类名`:自动创建建或复用 kb_categories

---

## 四、答案草稿风格统一标准(苏鸣后续可改)

| 原则 | 例子 |
|---|---|
| 1. **不编造具体数据**(WiFi 密码、价格、地址) | ❌"WiFi 密码是 XS888" → ✅"以云房卡为准" |
| 2. **指向云房卡/订单/API** | "请查看云房卡" "请提供订单号" "请联系掌柜" |
| 3. **50-150 字** | 太长客户不看 |
| 4. **不写"我"** | 用"建议""可以""通常"等中性词 |
| 5. **不承诺做不到的事** | ❌"保证 30 分钟内修好" |
| 6. **不主动推销** | 不引导客户换房、升级、加人 |

---

## 五、分类方案

把 [KB] 类按主题分到 6-8 个分类(避免全部混一起):

| 分类名 | 涵盖 |
|---|---|
| 入住与设备 | 入住时间、WiFi、门锁、退房、自助入住 |
| 设施与用品 | 设备使用、用品、毛巾、补给 |
| 周边与位置 | 附近、医院、便利店、地铁、交通 |
| 预订与价格 | 价格、房型、早餐、人数、宠物 |
| 支付与发票 | 押金、发票、付款、退款 |
| 订单变更 | 取消、改期、延住、转给别人 |
| 安全与卫生 | 噪音、卫生、虫、漏水、维修 |
| 通用与隐私 | 隐私、摄像头、删除个人信息 |
