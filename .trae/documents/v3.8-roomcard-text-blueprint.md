## 一、需求

客户发订单号 → AI 客服返回**文本消息**(含客房号、有效期、地址) + **urlLink 短链**(引导客户进小程序看密码/WiFi/验证)。

**绝不在文本/卡片中发密码**(门锁密码 / WiFi / 公安验证流程),只能让客户进小程序看。

## 二、关键决策(苏鸣 2026-08-15 明确)

| 字段 | 显示方式 |
|---|---|
| 客房号(roomCode) | ✅ **文本回复** |
| 有效期(expireTime) | ✅ **文本回复** |
| 小区地址(address) | ✅ **文本回复** |
| 门锁密码 | ❌ **永远不发,只走小程序** |
| WiFi 密码 | ❌ **永远不发,只走小程序** |
| 公安验证流程 | ❌ **永远不发,只走小程序** |

## 三、urlLink 短链

**使用**:`https://wxmpurl.cn/f1c4BdFdHDn`(程序员已配置小程序 urlLink.generate)

**所有客户共用同一个 urlLink**,小程序通过 unionid 识别客户身份。

## 四、改动范围

### 4.1 新建 `api/Workflow/OrderRoomCardWorkflow.php`

新 Workflow 处理"客户发订单号"场景:

```php
final class OrderRoomCardWorkflow extends AbstractWorkflow
{
    public function handle(): WorkflowResult
    {
        $orderNo = $this->intentCtx->slots['order_no'] ?? '';
        if ($orderNo === '') {
            return WorkflowResult::text('请提供订单号', 'OrderRoomCardWorkflow');
        }

        require_once __DIR__ . '/../wecom_kf_roomcard_v37.php';

        // 1. 查订单 - getRoomCard 返回 snake_case 顶层字段
        $card = getRoomCard($this->db, $orderNo);

        // 2. 查不到 → 生成(generateRoomCard 返回嵌套 card 对象,camelCase)
        if (!$card) {
            $card = generateRoomCard($this->db, $orderNo);
            if (!$card) {
                return WorkflowResult::text(
                    "未查询到您的云房卡信息,请确认订单号或联系前台协助。",
                    'OrderRoomCardWorkflow'
                );
            }
            // generateRoomCard 数据在嵌套 card 里
            $cardData = $card['card'] ?? null;
        } else {
            // getRoomCard 数据在顶层(snake_case)
            $cardData = $card;
        }

        // 3. 检查卡有效性
        $isInvalid = !empty($cardData['is_invalid']) || !empty($cardData['isInvalid']);
        $isExpired = !empty($cardData['is_expired']) || !empty($cardData['isExpired']);
        if ($isInvalid || $isExpired) {
            return WorkflowResult::text(
                "您的云房卡暂不可用,请联系前台协助。",
                'OrderRoomCardWorkflow'
            );
        }

        // 4. 构造回复(只显示客房号/有效期/地址,绝不显示密码)
        //   兼容两种数据源:snake_case(getRoomCard) / camelCase(generateRoomCard)
        $roomCode = $cardData['room_code'] ?? $cardData['roomCode'] ?? '';
        $expireTime = $cardData['expire_time'] ?? $cardData['expireTime'] ?? '';
        $expireTimeStr = is_numeric($expireTime) ? date('Y-m-d H:i', $expireTime) : $expireTime;
        $address = $cardData['address'] ?? '';

        $reply = "您的云房卡已就绪 🍊\n\n";
        if ($roomCode) $reply .= "🏠 房号:" . $roomCode . "\n";
        if ($expireTimeStr) $reply .= "⏰ 有效期至:" . $expireTimeStr . "\n";
        if ($address) $reply .= "📍 地址:" . $address . "\n";
        $reply .= "\n门锁密码、WiFi、公安验证请在小程序内查看 👇\n";
        $reply .= "https://wxmpurl.cn/f1c4BdFdHDn";

        return WorkflowResult::text($reply, 'OrderRoomCardWorkflow');
    }
}
```

## 六、风险与缓解

| 风险 | 缓解 |
|---|---|
| urlLink 过期(微信官方有有效期)| 定期刷新 urlLink(可挂 cron)|
| 客户点 urlLink 进小程序看到"通用预览"不是自己的卡 | 小程序读 unionid 自动识别;若失败,客户重新进小程序 |
| 重复订单号(不同客户的订单号可能撞)| 长数字 8-30 位,撞号概率极低 |
| generateRoomCard 返回 created_any: false | 卡已存在但 share_bundle 空 — 用现有数据 |
