# v3.33 订单查询回复删除「实付金额」行

## 需求（苏鸣 2026-11-20）

客户查订单的成功回复不再展示实付金额。改前：

```
订单查询成功：
房型：…
入住：…
离店：…
实付金额：¥132.88
如需查看云房卡请前往微信客服发送订单号获取。
```

改后：

```
订单查询成功：
房型：…
入住：…
离店：…
如需查看云房卡请前往微信客服发送订单号获取。
```

## 审计

- 唯一客户可见出处：`api/Workflow/OrderQueryWorkflow.php:71`（v3.26 引入）。
- `$paidAmount`（:64 行）赋值后仅被 :71 使用，删展示行后变量无用途，一并删除。
- `CenterApi::orderByChannelOrderId` 的 `paid_amount` 出参保留（注释/日志仍提到，接口层不动，以后要用随时可回加）。
- `scripts/regression_chat.php`、`tests/` 均无「实付」断言，无测试基线要改。
- openapi / 房管聊天接口返回的是原始 reply 文本，自动跟随，无独立文案。
- 微信客服房卡链路的 `roomCardTextPlan()` 第 1 条消息即本回复，自动少一行，无需改动。

## 改动

1. `api/Workflow/OrderQueryWorkflow.php`
   - 删 :64 `$paidAmount = ...;`
   - 删 :71 实付金额展示行

## 验证

1. `php -l api/Workflow/OrderQueryWorkflow.php`
2. 本地 MAMP `php scripts/regression_chat.php http://localhost:8888 --core`（若 MAMP 在跑）
