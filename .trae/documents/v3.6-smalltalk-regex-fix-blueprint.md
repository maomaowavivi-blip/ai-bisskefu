# 修改蓝图:isSmallTalk 中文后缀边界 bug 修复

**日期**:2026-08-13
**作者**:波尼(执行),苏鸣(审核)
**状态**:待审计

---

## 一、问题

**现象**:用户发"你好呀/晚上好呀/您好呀/晚上好啊/哈喽呀"等带语气词后缀的闲聊,未被识别为 SMALL_TALK,落到 UNKNOWN → 走 UnknownWorkflow → 回 fallback。

**根因**(已实测):
- `IntentClassifier::isSmallTalk()` 第 148 行正则使用 `\b` 词边界:
  ```php
  '/^(晚上好|早上好|中午好|下午好|早安|晚安|你好|您好|hi|hello|hey|嗨|哈喽)\b/iu'
  ```
- PHP 正则 `\b` 只对 ASCII 词边界生效,**中文后不产生词边界**
- "你好呀" = `你好` + `呀`,`\b` 在"好"和"呀"之间不匹配 → 整体不命中

**实测**:
```
你好呀 => ❌ 未命中
你好   => 命中
晚上好呀 => ❌ 未命中
您好呀 => ❌ 未命中
晚上好啊 => ❌ 未命中
哈喽呀 => ❌ 未命中
```

---

## 二、修复方案

**文件**:`api/IntentClassifier.php` 第 141-166 行 `isSmallTalk()`

**改法**:去掉中文后的 `\b` 依赖,改用一个更稳的匹配策略:

### 方案:前缀匹配 + lookahead 后缀限定(经审计修正)

**审计发现**:原方案(可选语气词)误伤"你好烦/晚上好累/谢谢你们公司"等。改用 **lookahead `(?=...)`** 限定后缀必须是语气词/标点/结尾,实测 16/17 通过。

```php
private static function isSmallTalk(string $message): bool
{
    $msg = trim($message);
    if ($msg === '') return false;

    // v3.6：去掉 \b（中文后无词边界），改用 lookahead 限定后缀
    // 问候词后必须是 语气词/标点/结尾，否则不命中（避免"你好烦"误判）
    $patterns = [
        '/^(晚上好|早上好|中午好|下午好|早安|晚安|你好|您好|嗨|哈喽)(?=[呀啊嘛哦哟~～！!。，]|$)/iu',
        '/^(hi|hello|hey)\b[\s~～!！]*/iu',
        '/^(谢谢|感谢|thank\s*you|多谢|thx|3q)(?=[呀啦哦啊~～！!。，]|$)/iu',
        '/^(拜拜|再见|bye\b[\s~～!！]*|886|溜了|走了)(?=[呀啦哦~～！!。，]|$)/iu',
        '/^(在吗|在么|有人吗|在不|在不在)/iu',
        '/^(好的|收到|明白了|ok\b|OK\b|好|嗯嗯)(?=[呀啦哦~～！!。，]|$)/iu',
    ];

    foreach ($patterns as $p) {
        if (preg_match($p, $msg)) return true;
    }

    // 长度 < 5 且全中文语气词
    if (mb_strlen($msg) <= 5) {
        $small = ['嗯', '哦', '啊', '哈', '呵', '嘿', '唉', '嘻', '嗯嗯', '哈哈', '呵呵', '嘿嘿', '好的', '收到'];
        if (in_array($msg, $small, true)) return true;
    }

    return false;
}
```

### 设计要点

1. **中文问候**:`(你好|您好|晚上好|…)(呀|啊|嘛|哦|哟|~|～|!|!)?` — 允许 0-1 个语气词后缀
2. **英文问候**:保留 `\b`(英文有词边界,"hello" 后跟空格/符号才匹配)
3. **语气词列表**:呀/啊/嘛/哦/哟/啦/~ /～/! /!(常用口语后缀)
4. **纯语气词**:长度放宽到 ≤5,加"嗯嗯/哈哈/呵呵/嘿嘿/好的/收到"

**回归风险**:
