## 一、问题清单(均已有实锤证据)

| # | 问题 | 证据 | 影响 |
|---|---|---|---|
| 1 | **emotion_strategy 未进入 system prompt** | `PromptEngine::buildSystem()` 只读取 name/description/personality/speak_style/service_rules/principles,无 emotion_strategy | 客户投诉时 AI 无情绪应对策略 |
| 2 | **service_rules 被整段过滤为空** | 代码按行 `explode("\n")` 后过滤含"掌柜"的行;但用户存的 service_rules 是**单行**包含"掌柜"→ 整段删除,实测结果为 `(空!)` | 服务边界规则完全不生效 |
| 3 | **principles 被 50 字符正则整段删除** | `preg_replace('/[^\n]{50,}/', '', $principles)` 把超过 50 字符的连续行整个删掉;实测结果长度 = 0 | 处事原则完全不生效 |
| 4 | **说话风格与默认话术"您"字冲突** | persona 说"称呼客人为您",但 buildSystem 默认话术含"3. 以'您'开头的问句或建议"(禁止用您反问) | AI 说话矛盾 |

## 二、修复方案

### 修复 1:emotion_strategy 进入 prompt(api/PromptEngine.php)

**位置**:`buildSystem()` 第 42-48 行附近 + 第 114-117 行后追加

```php
// 1. 读取(第 48 行后加)
$emotionStrategy = trim($persona['emotion_strategy'] ?? '');

// 2. 追加到 prompt(处事原则后)
if ($emotionStrategy) {
    $parts[] = '';
    $parts[] = '【情绪应对】' . $emotionStrategy;
}
```

**注意**:emotion_strategy 是纯行为指引(不含业务事实),进 prompt 安全,不违反"品牌故事不入 prompt"设计。

### 修复 2:service_rules 不再整段过滤(api/PromptEngine.php)

**问题**:过滤"掌柜"的逻辑是为了去掉"转接话术"避免 AI 复述,但单行存储导致整段删除。

**方案**:把过滤逻辑从"按行过滤"改为"只过滤转接话术片段":

```php
// 原代码(第 103-112 行)
$lines = explode("\n", $serviceRules);
$simpleRules = implode('。', array_map('trim', array_filter($lines, function ($l) {
    return mb_strlen(trim($l)) > 0 && mb_strpos(trim($l), '掌柜') === false;
})));
```

改为:

```php
// 新代码(修正版,经审计验证):按句号切分,过滤含"掌柜"的句子,其余保留
$sentences = preg_split('/[。]/u', $serviceRules, -1, PREG_SPLIT_NO_EMPTY);
$filtered = array_filter($sentences, function ($s) {
    return mb_strpos($s, '掌柜') === false;
});
$simpleRules = implode('。', array_map('trim', $filtered)) . '。';
```

**验证目标**(已实测通过):输入单行含掌柜的服务规则,输出保留"以下事项超出自动回复范围…须转人工处理…对于不确定的信息…"等规则,删除"掌柜为您处理"句。实测:含掌柜=NO,长度 135。

### 修复 3:principles 不再截断(api/PromptEngine.php)

**问题**:`preg_replace('/[^\n]{50,}/', '', $principles)` 本意是"删除过长行",但实际把所有超过 50 字符的行全删了(中文字符 > 50 太常见)。

**方案**:改为分段插入,不删除:

```php
// 原代码(第 116 行)
$parts[] = '【处事原则】' . trim(preg_replace('/[^\n]{50,}/', '', $principles));

// 新代码:直接使用完整原则(系统 prompt 长度足够,无截断必要)
$parts[] = '【处事原则】' . trim($principles);
```

**验证目标**:principles 全文进入 prompt,长度 > 0。

### 修复 4:"您"字冲突(api/PromptEngine.php)

**问题**:默认话术第 3 条"以'您'开头的问句或建议"与 persona"称呼您"冲突。

**方案**:默认话术改为禁止"反问式追问"(保留用您称呼,禁止追问):

```php
// 原(第 74 行)
$parts[] = '3. 以"您"开头的问句或建议';

// 新
$parts[] = '3. 反问式追问(如"您是想了解什么吗""需要我帮您吗")';
```

**说明**:默认话术仅当 DB `agent.rules.speech_bans` 未配置时使用;若已配置,以 DB 为准。
