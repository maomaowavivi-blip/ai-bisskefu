## 一、问题

KB 向量化阻塞。149 条 KB 中 105 条没有向量,44 条是 **1536 维**(MiniMax 旧 model 生成的)。客户端问问题,`kbSemanticSearch` 检索依赖 KB 向量,**部分 KB 无法被语义搜到**,回答命中差。

**根因**:
1. MiniMax `embo-01` API 返回 1008 `insufficient balance`(苏鸣买的 MiniMax token plan 不含 embedding 套餐)
2. 切到阿里云 DashScope `text-embedding-v3` 后,**API 仅支持 64/128/256/512/768/1024 维**,不支持 1536
3. 已有的 44 条 1536 维向量与新的 1024 维**不兼容**,混存会导致 `cosineSimilarity` 计算错乱

## 二、改造内容

### 2.1 改 `api/embedding.php` 切到 DashScope

**改动范围**:仅 `callEmbeddingAPI()` 与 `getEmbeddingApiKey()` 两个函数

```php
function getEmbeddingApiKey(): string {
    // 优先:DB 的 ai.api_key.qwen_embedding(Qwen/DashScope)
    // fallback:原 ai.api_key.minimax_backup(保留兼容,不动)
    $key = trim(strval(pcGet(getDB(), 'ai.api_key.qwen_embedding', '')));
    if (!$key) {
        // 兼容:envVal('MINIMAX_API_KEY', '') 或 ai.api_key.minimax_backup
        try {
            $db = getDB();
            $key = trim(strval(pcGet($db, 'ai.api_key.minimax_backup', '')));
        } catch (Exception $e) {}
    }
    return $key;
}

function callEmbeddingAPI(array $texts, string $type = 'db'): array {
    $apiKey = getEmbeddingApiKey();
    if (!$apiKey) throw new RuntimeException('AI 未配置:platform_config.ai.api_key.qwen_embedding');

    $provider = trim(strval(pcGet(getDB(), 'ai.embedding_provider', 'dashscope')));
    $url = trim(strval(pcGet(getDB(), 'ai.embedding_api_url', 'https://dashscope.aliyuncs.com/compatible-mode/v1/embeddings')));
    $model = trim(strval(pcGet(getDB(), 'ai.embedding_model', 'text-embedding-v3')));

    if ($provider === 'dashscope') {
        // 阿里兼容 OpenAI 协议
        $body = [
            'model' => $model,
            'input' => $texts,                       // 注意:用 input 不是 texts
            'encoding_format' => 'float',
        ];
        $headers = ['Content-Type: application/json', 'Authorization: Bearer ' . $apiKey];
    } else {
        // 原 MiniMax 兼容路径(本次不删,留 fallback)
        $body = ['model' => $model, 'texts' => $texts, 'type' => $type];
        $headers = ['Content-Type: application/json', 'Authorization: Bearer ' . $apiKey];
    }

    $ch = curl_init($url);
    curl_setopt_array($ch, [
        CURLOPT_POST => true,
        CURLOPT_POSTFIELDS => json_encode($body, JSON_UNESCAPED_UNICODE),
        CURLOPT_RETURNTRANSFER => true,
        CURLOPT_TIMEOUT => 60,
        CURLOPT_HTTPHEADER => $headers,
    ]);
    $resp = curl_exec($ch);
    $httpCode = curl_getinfo($ch, CURLINFO_HTTP_CODE);
    curl_close($ch);

    if (!$resp) throw new RuntimeException('Embedding 请求失败');
    if ($httpCode !== 200) throw new RuntimeException('HTTP ' . $httpCode . ': ' . substr($resp, 0, 200));

    $json = json_decode($resp, true);
    if (!is_array($json)) throw new RuntimeException('返回非 JSON');

    // DashScope 返回格式:{ data: [{embedding: [...]}] }
    // MiniMax 返回格式:{ vectors: [...] }
    if ($provider === 'dashscope') {
        $vectors = array_map(fn($d) => $d['embedding'] ?? [], $json['data'] ?? []);
    } else {
        $vectors = $json['vectors'] ?? [];
    }
    if (empty($vectors)) throw new RuntimeException('返回为空: ' . substr($resp, 0, 200));

    return $vectors;
}
```

### 2.2 清空旧的 1536 维向量(本地 + 线上)

```sql
UPDATE kb_entries
SET embedding_vector = NULL, embedding_updated_at = NULL
WHERE embedding_vector IS NOT NULL;
```

**44 条 1536 维向量将被清空,内容(answer/question)不动**。

### 2.3 跑批量向量化

调 `POST /api/embedding.php?action=batch_vectorize`,每次 50 条,直到全部 149 条完成。

预计 149 ÷ 10 = **15 轮**(本地 + 线上各 15 轮,共 30 次调用)。

### 2.4 同步线上 DB

- 本地代码改完 + 测试通过 → scp 到 VPS + md5 校验
- 本地 DB `platform_config` 4 行 → 在线 DB 同步
- 线上清旧 44 条 → 跑 3 轮向量化
- 最后 audit:线上 149 条全部 1024 维

## 三、不动的部分

| 项 | 不动原因 |
|---|---|
| `vectorize` / `batch_vectorize` HTTP action | 不需改,只是改底层 API 调用 |
| MiniMax fallback 路径 | 留兼容,万一以后又用 MiniMax 不用改函数体 |
| `cosineSimilarity` 算法 | 不改逻辑,但**加维度检查防御**(维度不一致返 0) |

## 四、风险与缓解

| 风险 | 缓解 |
|---|---|
| 清空 44 条旧向量,**部分 KB 短期内搜不到** | 立即跑向量化补回 |
| 阿里 v3 与原 MiniMax 1536 维的语义空间不同,**部分 KB 命中率波动** | 接受短期波动,1-2 天观察 |
| 阿里 v3 单次最多 10 条/批 | batch 50 → 改 10(已实测确认)|
| 阿里 key 泄露 | key 只存 DB,不入源码/commit |
